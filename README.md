# This Repository has been moved to [Codeberg](https://codeberg.org/clxxiii)

 **This is not a mirror**, all history has been removed and is now hosted at the codeberg location.

 ## Why?

 Not only is GitHub is owned by Microsoft, a company on the [BDS List](https://bdsmovement.net/Guide-to-BDS-Boycott)
 cited as "[perhaps the most complicit tech company in Israel's illegal apartheid regime](https://bdsmovement.net/Guide-to-BDS-Boycott#:~:text=perhaps%20the%20most%20complicit%20tech%20company%20in%20Israel%E2%80%99s%20illegal%20apartheid%20regime)", GitHub itself is no longer focused on providing git-like services
 to the public other than the purposes for gaining more training data. In fact, it decided to
 [train private repo data for it's AI](https://www.theregister.com/software/2026/03/26/github-we-going-to-train-on-your-data-after-all/5229507)
 in which all users are opted-in by default, which is why the history has been removed.

 In GitHub's own words: "[Just as GitHub was founded on Git, today we are re-founded on Copilot.](https://github.blog/news-insights/product-news/universe-2023-copilot-transforms-github-into-the-ai-powered-developer-platform/#:~:text=Just%20as%20GitHub%20was%20founded%20on%20Git%2C%20today%20we%20are%20re%2Dfounded%20on%20Copilot.)"

 ## Why Codeberg?

 Codeberg is [open source, and hosted by a non-profit](https://docs.codeberg.org/getting-started/what-is-codeberg/).
 As a result, it focuses more on the needs of small, independent developers and projects (like me!) rather than
 spending any time trying to accomodate massive teams of developers with the need for lots of compute, storage, and
 tooling.

 Additionally, Codeberg [banned 'majorly written by LLM' projects](https://blog.codeberg.org/protecting-our-floss-commons-from-llms.html), 
 and [banned all Crypto-related projects](https://codeberg.org/Codeberg/org/commit/f383b648fd733ab88083dc390b91e77cd7589980) 
 from the platform. While controversial, none of my projects are "majorly written by LLM's" and I agree with almost every
 reason as to why they banned LLMs in the first place. If some day I decide to make a project that is vibe-coded, it'll
 be hosted on [tangled](https://tangled.org) (which many of my projects are already mirrored to anyways.)
